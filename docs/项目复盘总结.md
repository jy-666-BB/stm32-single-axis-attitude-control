# STM32 MPU6050 姿态稳定与舵机控制项目复盘

## 一句话定位

这是一个基于 **STM32F103C8T6 + MPU6050 + 舵机** 的单轴姿态闭环控制练习项目。系统以 100 Hz 读取 MPU6050 的加速度计、陀螺仪数据，采用互补滤波估算 Roll（横滚）角，再通过 PID（当前参数实际为 PD）让舵机向相反方向转动，使被控结构趋近于水平位置。

项目目录名为 `GestureDetection`，但就目前代码实现而言，它**不是离散手势分类项目**：没有采集手势时间序列、特征提取、阈值状态机或机器学习分类器。更准确的项目名称可以写为“基于 MPU6050 的单轴姿态稳定/舵机平衡控制”。若实物是手持结构，也可称为“手势驱动的姿态响应演示”，但不要表述为“完成了手势识别”。

## 做了些什么

### 1. 搭建 STM32 外设与硬件接口

- 主控为 STM32F103C8T6，外部晶振经 PLL 配置为 72 MHz。
- I2C1（PB6/SCL、PB7/SDA）以 100 kHz 与 MPU6050 通信，器件地址为 `0x68`。
- TIM2 CH1（PA0）产生 50 Hz PWM 驱动舵机；计数器分辨率为 1 us，周期为 20 ms。
- TIM3 产生 10 ms 周期中断，作为姿态更新与控制环的固定节拍，即理论控制频率 100 Hz。
- USART1（PA9/PA10，115200 bps）用于串口打印 Roll、控制输出和舵机角度，便于调试观察。
- 代码中还封装了 PC13 LED 和串口重定向，其中 LED 当前没有进入主控制逻辑。

### 2. 完成 MPU6050 的初始化、采样与静态标定

程序依次完成唤醒、采样率分频、数字低通滤波、加速度计量程和陀螺仪量程配置：

- `PWR_MGMT_1 = 0x00`：退出休眠；
- `SMPLRT_DIV = 0x07`：在陀螺仪内部 1 kHz 输出率、DLPF 开启的条件下，理论采样率约为 125 Hz；
- `CONFIG = 0x03`：设置 MPU 内部低通滤波；
- `GYRO_CONFIG = 0x00`：陀螺仪 ±250 °/s，对应 131 LSB/(°/s)；
- `ACCEL_CONFIG = 0x00`：加速度计 ±2 g，对应 16384 LSB/g。

启动后程序在设备静止状态下采集 1000 组数据并取均值：陀螺仪三轴理论静止值为 0，加速度 X/Y 理论值为 0 g、Z 理论值为 1 g，因此对 Z 轴偏置额外减去 16384。随后将原始 16 位数据换算为 g 和 °/s。

### 3. 利用互补滤波估算姿态角

加速度计根据重力方向计算倾角：

```text
AccRoll  = atan2(AccY, AccZ)
AccPitch = atan2(-AccX, sqrt(AccY² + AccZ²))
```

陀螺仪角速度经过积分可得到快速、平滑的短期角度，但会随零偏积累漂移；加速度计能够利用重力提供长期参考，但会被运动加速度和振动扰动。项目以如下互补滤波融合两者：

```text
Roll(k) = 0.98 × [Roll(k-1) + GyroX × dt] + 0.02 × AccRoll
```

这意味着每个控制周期主要信任陀螺仪预测，同时以较小比例用加速度计校正长期漂移。代码同时计算 Pitch，但当前闭环只使用 Roll。

### 4. 形成单轴 PID 闭环并驱动舵机

控制目标设为 `Roll = 0°`，控制误差为 `target - measure`。PID 模块具有 P、I、D 三项和输出限幅能力；主程序将参数设置为 `Kp=2.0, Ki=0, Kd=0.1, Max_Output=45`，所以当前运行的是 **PD 控制**：

```text
输出 = 2.0 × 误差 + 0.1 × 误差变化率
舵机目标角 = 90° + 输出
```

舵机命令进一步限制在 45°～135°，以 90° 为机械中位。其本质是负反馈：当检测到横滚偏差时，PID 产生校正量，让舵机移动以抵消偏差。串口每 10 个控制周期打印一次，即约 10 Hz，避免大量日志影响实时控制。

## 软件结构与数据流

```text
MPU6050
  └─ I2C 原始 6 轴数据
       └─ 静态偏置补偿 + 物理单位换算
            └─ 加速度计倾角 + 陀螺仪积分
                 └─ 互补滤波 → Roll / Pitch
                      └─ Roll 目标 0° 与测量值比较
                           └─ PD/PID 输出限幅
                                └─ TIM2 PWM → 舵机

TIM3 每 10 ms 触发一次上述采样、估计和控制；USART 输出调试量。
```

主要文件职责：

| 文件 | 职责 |
| --- | --- |
| `Core/Src/main.c` | 上电初始化、定时回调、总控制流程 |
| `Hardware/MPU6050.c` | MPU6050 寄存器配置、读取、标定、单位换算 |
| `Application/attitude.c` | Roll/Pitch 计算与互补滤波 |
| `Application/pid.c` | PID 状态保存、计算与输出限幅 |
| `Hardware/pwm.c` | 舵机 PWM 启动与角度到脉宽换算 |
| `Core/Src/tim.c` | TIM2 舵机 PWM、TIM3 10 ms 定时中断 |
| `Hardware/retarget.c` | 将 `printf` 重定向到 USART1 |

## 最需要吃透的知识点

1. **定时与真实 dt**：TIM3 的预分频和重装值使中断约为 10 ms，滤波和微分项都依赖 `dt=0.01 s`。一旦实际周期漂移、回调超时或频率改变，却没有同步修改 `dt`，姿态积分和 D 项都会失真。
2. **量程决定比例系数**：`16384 LSB/g` 与 `131 LSB/(°/s)` 只适用于当前 ±2 g、±250 °/s 的寄存器配置；改量程必须同步改换算系数。
3. **静态标定的前提与边界**：校准时板子必须真正静止且朝向与代码假设一致；这种均值法只能修正零偏，不能消除比例误差、轴不正交、温漂和机械安装误差。
4. **互补滤波的物理意义**：陀螺仪负责高频动态，重力方向负责低频绝对参考。`0.98/0.02` 是经验权重，振动更大时应降低加速度计权重，响应太慢或漂移明显时再调整；不能只把它当作固定公式。
5. **PID 的调参与符号**：先确认“倾斜方向—Roll 正负—舵机正转”的符号链。若发生越偏越大，应先反转舵机/误差方向，而不是盲目增大 Kp。通常先调 P，再加 D 抑制振荡，最后视需要加入很小的 I 消除稳态误差。
6. **PWM 到实际舵机角度不是完全线性**：代码用 500–2500 us 映射 0–180°，但不同舵机可接受的脉宽、机械中位和有效角度不同，应实测校准，并设定不顶机械限位的安全范围。
7. **中断实时性与共享数据**：当前在 TIM3 中断中执行阻塞式 I2C 读和浮点 `atan2/sqrt` 计算；主循环又异步读取并打印由中断更新的全局量。这适合入门验证，但要知道它对实时性、串口调用和数据一致性都有影响。

## 当前实现的亮点

- 从传感器寄存器配置、原始数据读取、偏置校准，到姿态融合、控制器、PWM 执行器和串口调试，已经搭起了一条完整的嵌入式闭环链路。
- 模块划分清楚：传感器、姿态解算、PID、PWM 与 CubeMX 生成的底层配置相互分层，便于独立调试和替换。
- 控制周期、控制输出、舵机角度均有明确限幅，且用低频打印降低调试输出对系统的干扰。

## 当前局限与下一步改进

1. `MPU6050_GetData()` 将每个字节拆成一次 I2C 寄存器读，共 12 次事务。更合理的方式是从 `0x3B` 开始连续读取 14 字节（含温度），减少总线开销并保证一帧数据的时间一致性。
2. HAL I2C 读写的返回值未检查；应加入设备 ID（`WHO_AM_I`）校验、超时/错误处理和传感器掉线保护。
3. 在中断里做阻塞 I2C 和较重的浮点计算，存在延长中断占用、影响系统响应的风险。可采用“定时器置采样标志 + 主循环处理”、DMA/中断式 I2C，或至少测量回调执行时间。
4. `Servo_SetAngle` 的参数类型是 `uint8_t`，但调用点传入的是 `float`；当前会隐式截断小数。若希望保持控制精度，应把接口改为 `float` 或显式规定量化策略。
5. PID 虽有积分累计，但没有积分限幅/抗积分饱和；当前 `Ki=0` 因而不受影响。一旦开启 Ki，舵机饱和时可能累积积分并造成恢复过冲。
6. PID 的 D 项对测量噪声较敏感。IMU 振动场景下可考虑“对测量值求导”、一阶低通滤波或更规范的姿态滤波器（Mahony/Madgwick）。
7. 只控制 Roll，Pitch 虽计算但未使用；下一步可扩展成双轴云台/双舵机控制，但需要处理两个轴的机械耦合、舵机中位和独立 PID 参数。
8. 若项目目标确实是“手势识别”，还需要另加窗口化采样、动作开始/结束检测、特征（峰值、持续时间、积分角位移等）和分类策略；现有系统可作为很好的 IMU 数据采集与姿态预处理基础。

“独立完成基于 STM32F103、MPU6050 与舵机的单轴姿态稳定系统：通过 I2C 配置并采集六轴 IMU 数据，完成静态零偏标定；以加速度计重力倾角和陀螺仪积分构建互补滤波，100 Hz 输出 Roll 姿态；设计带限幅的 PD 闭环，将姿态误差实时映射为 50 Hz PWM 舵机控制量，并通过串口观测姿态与控制输出完成调参。”

答辩时可主动说明：这套系统的核心价值不是“识别手势类别”，而是完成了一个从传感、估计到执行的实时闭环控制原型；其进一步演进方向是优化采样一致性和实时性、提高滤波/控制鲁棒性，以及在此基础上增加真正的动态手势分类。
